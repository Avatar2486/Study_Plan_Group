## How to Use This Folder

1. **Week before interview:** Do 1 Pramp session (behavioral) + 1 DSA mock on LeetCode
2. **Day before:** Record yourself answering [[Interview/Self Interview/HR Questions]] out loud
3. **Morning of interview:** Read [[About Me/Profile]] — refresh your numbers

---

## Self-Practice Checklist

- [ ] "Tell me about yourself" — under 75 seconds
- [ ] STAR story for a challenge
- [ ] STAR story for a success
- [ ] Salary expectation answer ready
- [ ] 3 questions to ask them ready
- [ ] System design: explain one project's architecture

## System Design Questions to Prepare

Based on Abhishek's stack:
1. Design a file translation pipeline (CSV batch processing, 500+ files/day)
2. Design a real-time notification system (WebSockets + Redis)
3. Design a scraping system at scale (50K records/day, IP rotation)
4. Design an email automation pipeline (Gmail API → Lambda → S3)
