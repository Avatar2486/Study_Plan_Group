# Templates

> Copy any template, rename it, fill it in. Delete what you don't need.
> These make the vault reusable for any topic or any person.

---

## Available Templates

| Template | Use When |
|----------|----------|
| [New Topic.md](New%20Topic.md) | Starting to study a new language, tool, or concept |
| [New Answer Bank.md](New%20Answer%20Bank.md) | Creating answers for a topic file |

---

## How to use (3 steps)

1. **Copy** the template file → paste in the right folder
2. **Rename** it to your topic (e.g., `TypeScript.md`)
3. **Replace** every `{{placeholder}}` with real content — then delete this line

---

## Folder conventions

```
Study Plan/
  YourTopic.md          ← topic list (use New Topic template)
  Answer Bank/
    YourTopic.md        ← answers (use New Answer Bank template)
```

---

## Someone else using this vault

If you're forking this for yourself:
1. Delete everything inside `Study Plan/` (keep folder structure)
2. Delete `About Me/`, `Interview/`, `HR Connections/`, `What To Say/` content
3. Update `README.md` with your name + stack
4. Start with one topic using the `New Topic` template
5. After studying, log it in `Study Plan/Study Log.md`
6. Update `Study Plan/Progress Tracker.md` with your status + confidence
